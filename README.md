# Ladakh Heritage — Varkala

Responsive React + Vite + Tailwind CSS v4 website concept. Styling is implemented using Tailwind utility classes in `src/App.jsx`; `src/index.css` contains only Tailwind import, theme tokens, and basic global defaults. Supplied shop photos are included in `public/`.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually http://localhost:5173.

## Before publishing
- Confirm the shop owner's preferred wording, store hours, phone/WhatsApp number and social links.
- Replace or supplement the supplied photos with high-resolution, owner-approved product photography.
- Verify the address and Google Maps pin with the owner.
- Add real product names/prices only if the store wants a catalogue.

This is a presentation concept, not yet an ecommerce system. It does not include checkout, payments, inventory management or a live product catalogue.
